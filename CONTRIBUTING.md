# Contributing to Veil Player

Thank you for your interest in Veil Player! Veil Player is currently operating under a strict **Release Freeze** for Version 1.0. 

## Version 1.0 Release Freeze
- **Feature development is permanently frozen for v1.0.**
- We are not accepting pull requests for new features, UI redesigns, or architectural changes at this time.
- Only critical bug fixes and stability improvements will be reviewed.

## How to Report Bugs
If you find a reproducible bug, please open an issue providing:
1. Steps to reproduce
2. Expected behavior vs actual behavior
3. Android OS version and device model
4. Stack traces if a crash occurred

## Development Setup
Veil Player uses Flutter and `fvm` (Flutter Version Management). 
1. Install `fvm`.
2. Run `fvm flutter pub get`.
3. Run `fvm flutter run` to test locally.
