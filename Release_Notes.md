# Veil Player - Version 1.0 Release Notes

Welcome to Veil Player Version 1.0!

After extensive internal testing and refinement, Veil Player has reached its first stable release milestone. 

## The Premium Offline Media Experience
Veil Player was built from the ground up to be the cleanest, fastest, and most privacy-respecting media player for Android. No ads. No telemetry. No internet required.

## Key Features in 1.0

### Uncompromised Playback Engine
Powered by `media_kit`, Veil Player natively supports hardware acceleration for all modern codecs. Software fallback ensures older files play without a hitch. Adjust subtitle delays, audio synchronization, and playback speeds on the fly.

### Smart Quick Access
Veil Player's library intelligently curates your storage. It automatically detects folders like Camera, Downloads, and Movies, while actively filtering out cache, thumbnails, and looping GIFs from messenger apps. Your library remains pristine and focused solely on what you want to watch.

### True AMOLED Design
Built with a 120Hz-first philosophy, every interaction is supported by fluid micro-animations. The Pure Pitch Black theme disables pixels on AMOLED screens to save battery while watching.

### Deep System Integration
- **Background Playback**: seamlessly transitions to a foreground service with lock screen and notification controls.
- **Picture-in-Picture**: true native PiP support for multitasking.
- **Audio Focus**: Automatically pauses when you receive a call, and plays when you reconnect your Bluetooth headphones.

### Known Issues & Ongoing Work
- Version 1.0 is currently under a strict Feature Freeze. Only critical bugs affecting stability or memory leaks will be addressed in upcoming 1.0.x patches.

Enjoy the ultimate offline media experience.
