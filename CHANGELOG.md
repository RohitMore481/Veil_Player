# Changelog

All notable changes to Veil Player will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-09

### Added
- Initial public release of Veil Player.
- Hardware-accelerated offline video playback engine powered by media_kit.
- Gesture controls for brightness, volume, and horizontal seeking.
- Smart Quick Access logic to curate video-containing folders automatically.
- Custom AMOLED pure black design system with micro-animations.
- Picture-in-Picture (PiP) support for background playback.
- Subtitle and audio track selection with manual delay synchronization.
- Seamless Android MediaSession integration (Bluetooth controls, notification controls, lock screen).
- Smart library tracking with watched history and "Continue Watching" hero cards.
- Comprehensive file operations (Rename, Delete, Hide).
